# Brute Browser

Android WebView-based browser with integrated developer tools.

## Features

- **JS Inject**: Run arbitrary JavaScript in the current page
- **Commands**: 15 built-in developer utility scripts (cookie dump, DOM inspection, performance timing, fetch monitoring, etc.)
- **User Agent**: 6 browser presets + custom UA override
- **Proxy / VPN**: Manual proxy config + region VPN presets
- **History**: Browsing history with quick re-open
- **Settings**: JavaScript/images/cookies toggles
